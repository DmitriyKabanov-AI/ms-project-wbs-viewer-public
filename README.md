# 📄 README.md для WBS Viewer + EVM + Analytics

## 1. Назначение и возможности

**WBS Viewer + EVM + Analytics** — это веб-приложение, разработанное на Python с использованием Flask, pandas и openpyxl, предназначенное для удобного анализа структуры работ (Work Breakdown Structure, WBS), управления проектами и аналитики по методологии Earned Value Management (EVM).

Основные функции приложения:

- **Парсинг XML-файлов MS Project:** импорт структуры работ (WBS) из MS Project.
- **Иерархическая визуализация:** интерактивная визуализация дерева работ с возможностью группировки и фильтрации.
- **Метрики EVM:** расчет ключевых метрик (SPI, CPI, CV, SV).
- **Ручные заметки:** возможность добавлять комментарии и заметки к задачам (хранятся в файле `notes.json`).
- **Экспорт результатов:** экспорт данных в формате Excel.
- **Аналитика изменений:** сравнение текущего состояния проекта с предыдущим («Было / Стало»).
- **RAG-анализ:** оценка статуса выполнения проекта и исполнителей по шкале Red/Amber/Green.
- **Тепловые карты загрузки ресурсов:** наглядное представление загруженности ресурсов.
- **Прогнозирование сроков завершения:** прогноз даты окончания проекта на основании текущих показателей.

## 2. Установка и зависимости

Для установки и запуска приложения необходимы следующие библиотеки и инструменты:

### Библиотеки Python:
```
pip install flask pandas openpyxl beautifulsoup4 lxml requests
```

### Дополнительные требования:
- Установите Python версии >= 3.8.
- Установите браузер Google Chrome или Chromium для корректной работы интерфейса.

## 3. Структура проекта

Файлы и папки проекта организованы следующим образом:

```
ms-project-wbs-viewer/
├── data/
│   ├── xml_data/              # XML-файлы MS Project
│   ├── xml_snapshots/         # Срезы для аналитики (Было/Стало)
│   ├── notes.json             # Заметки к задачам
│   └── manual_mapping.json    # Ручные привязки
├── src/
│   ├── analytics/             # Модуль аналитики
│   │   ├── __init__.py
│   │   └── analytics_engine.py
│   ├── server.py              # Flask-сервер
│   └── wbs_parser.py          # Парсер MS Project XML
├── templates/
│   ├── analytics.html         # Страница аналитики
│   └── index.html             # Главная страница WBS Viewer
├── logs/                      # Логи (создаётся при запуске)
├── run.py                     # Точка входа
├── requirements.txt
└── README.md

## 4. Запуск локального сервера

Запустите приложение командой:
```
python run.py
```

После запуска откройте браузер и перейдите по адресу http://localhost:5000/.

## 5. Использование (основной интерфейс и аналитика)

Интерфейс приложения интуитивно понятен и включает несколько основных элементов:

- Импорт XML-файла MS Project через форму на главной странице.
- Просмотр и навигация по структуре работ (WBS).
- Доступ к отчету по ключевым метрикам EVM.
- Возможность просмотра и редактирования заметок к задачам.
- Анализ текущего состояния проекта и сравнения с прошлым состоянием.
- Оценка загрузки ресурсов и прогнозирование сроков завершения.

## 6. Формат входных данных (XML из MS Project)

Формат XML-файлов должен соответствовать стандартному формату MS Project, то есть сохранить как в формате XML
